## Method

1. **Identifiers.** The datasets share no identifier field. A DILG project code written in a DPWH title, or a DPWH contract id written in a DILG title or component list, counts as an exact match.
2. **Blocking.** Only DPWH contracts in the same PSGC province and infra year within ±1 of the DILG funding year, sharing at least one informative title word, are compared.
3. **Title similarity.** IDF-weighted overlap of normalized title words (accents, punctuation, abbreviations such as FMR / MPH / CR expanded, generic verbs like "construction" removed). The DILG record's own province, city/municipality and barangay names are removed from both titles first, so a shared place name alone cannot make titles look alike.
4. **Location.** DPWH has no municipality or barangay columns (always empty), so location is read from the DPWH title: every PSGC barangay name of the DILG city/municipality is looked up in both titles. Same barangay = strong; only the city/municipality named = weak; a different barangay, or a different city/municipality of the province, = not the same project. Every place name found in either title is removed before titles are compared. DPWH coordinates within 3 km (barangay-level DILG location) or 12 km (municipality-level) of the DILG area centroid add a little weight; province-level DILG locations never count as near.
5. **Cost, year, contractor.** DILG cost vs DPWH contract amount (else approved budget / budget); same year; same normalized contractor name.

- **Exact:** identifier cross-reference, or title ≥ 90% similar AND same year AND cost within 1% AND the same barangay named in the DPWH title.
- **Potential:** title ≥ 75% AND same barangay; or title ≥ 50% AND same barangay AND (cost within 10% OR same contractor OR same year); or title ≥ 75% AND only the same city/municipality named AND (cost within 10% OR same contractor); or title ≥ 35% AND cost within 10% AND same contractor.
- **Never flagged:** the DPWH title names a different barangay of the same city/municipality (or a different city/municipality of the province) and not the DILG one; the two titles describe different kinds of work (road / water / flood works vs a building); or one cost is over 4× the other unless title, barangay and year all agree.
- **No match:** compared, nothing met those rules.

## Limitations

- No shared identifier exists, so every non-identifier match is probabilistic and needs a person to confirm it.
- DPWH rows carry no municipality or barangay; location agreement relies on place names inside DPWH titles and on DPWH-reported coordinates (6% of DPWH rows have none).
- DILG coordinates are area centroids, not project sites, so distance is only a coarse signal; province-level DILG rows get no distance evidence.
- 19k RLIP rows (mostly not yet started) have no cost, removing the cost signal for them.
- Only DILG rows in the DPWH import scope (Visayas and Mindanao, years 2015–2026) can be compared; Luzon and NCR rows are "not comparable", not "no match".
- DPWH province labels that could not be mapped to a PSGC province (their contracts are not compared): "Isabela", "Maguindanao", "Metropolitan Manila".
- Thresholds were set by inspecting samples, not against a labelled set; expect both misses and false flags.
